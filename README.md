# Polabot downloads

Installers and release notes for [Polabot](https://polabot.app): a team of always-on polar bear bots that run on the AI subscriptions you already have.

| | |
|---|---|
| macOS (Apple silicon and Intel) | `.dmg` — signed and notarized |
| Windows 10 / 11 (x64) | `.exe` installer |
| Linux and Mac mini, headless | `curl -fsSL https://polabot.app/install.sh \| sh` |
| iPhone | TestFlight, from [polabot.app/download](https://polabot.app/download) |

Get the current version from the [latest release](../../releases/latest), or from [polabot.app/download](https://polabot.app/download).

The desktop app updates itself from this repository.
